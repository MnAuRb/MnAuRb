### 🧠 亲友记忆 Agent

> 武汉 NextStep 48h 黑客松 · 多模态输入的可信亲友记忆系统

| 维度 | 说明 |
| --- | --- |
| 💡 **核心创意** | 竞品调研 13+ 产品后锁定空白点：做「可信验证」而不是「复刻」—— 把 AI 陪伴从情感口号变成可验证的工程问题 |
| 🎯 **我的角色** | 产品定义 + 后端交付。提出「可信人格 + 可信记忆 + 可审计」三大引擎、三不原则（不编造 / 不替代 / 不伤害）、情感状态机与记忆审计面板 |
| 🏗️ **技术亮点** | 结构化人格引擎：10 个人格维度（性格 / 表达风格 / 兴趣 / 关系 / 世界观 / 禁忌边界等），置信度 = f(证据数量, 多模态交叉, 时间一致性)，低置信字段自动降级，persona_version 支持版本管理<br>Memory Audit v2：FastAPI + SQLAlchemy 分层架构（models / services / schemas / api / tests），8 个审计 API 端点，18 类审计事件 × 4 级严重度，15 个自动化测试 |
| 🏆 **结果** | 独立交付 Memory_Audit_v2 后端 + 前端 + 设计规范，入选路演前 8 |
| 💭 **我学到了** | 这是我第一次参加黑客松，也是从角色真空到独立交付的三天。最痛的一课是「知识的诅咒」—— 信任不是承诺出来的，是系统证明出来的：可溯源、可审计、可修正，用户才敢托付 |
